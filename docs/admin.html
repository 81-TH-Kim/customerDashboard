🔗 GitHub 연결 (화면에서 저장 → 즉시 반영)

연결하면 저장 버튼 한 번으로 사이트에 반영됩니다(1~2분). 토큰은 이 브라우저에만 저장되며 저장소에 올라가지 않습니다.
GitHub → Settings → Developer settings → Fine-grained tokens → customerDashboard 저장소, Contents: Read and write, 만료 짧게.

📥 데이터 업로드 (로컬 → 서버)

로컬 data/live/ 의 파일을 골라 서버(Render)에 올립니다. 초기 1회 또는 수동 갱신 시. 이후에는 자동 수집(매일)이 서버에서 데이터를 채웁니다.

제휴채널 관리

code 는 메일 본문값(수정 불가)
code표시명채널유형 사용노출순서

저장 및 적용 — GitHub 연결 시 즉시 반영(1~2분). 미연결이면 파일로 저장 후 data/live/channels.json 교체 → publish.bat. 노출='N' 채널은 대시보드/PDF에서 숨겨지지만 수집 데이터는 유지됩니다. 행을 드래그해 순서 변경.
